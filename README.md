# Aegis IOS

Aegis Investment Operating System is an enterprise-grade, AI-agnostic operating system for governing investment decision workflows.

## Repository map

The numbered directories follow the product lifecycle from foundation and governance through runtime, implementation, and assets. `archive/` contains superseded, retained artifacts only.

## Status

Foundation repository, version 0.1.0.

Read `00_Foundation/CONST-001_Aegis_IOS_Constitution.md` before proposing substantive changes. All changes follow the RFC → ADR → implementation path in `01_Governance/`.
